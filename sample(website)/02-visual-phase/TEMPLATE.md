# Шаблон: Фаза 2 (Визуальный дизайн и UX)

## 1. Общий Стиль и Вайб (Выберите 1-2 варианта)
- [ ] **Bento Box:** Дизайн из плотно упакованных карточек с закругленными углами (стиль презентаций Apple).
- [ ] **Glassmorphism:** Эффект "матового стекла". Полупрозрачные панели, сквозь которые красиво размывается яркий фон.
- [ ] **Dark Elegance (Темный премиум):** Глубокий черный фон, тонкие неоновые линии, свечение (Glow). Дорого и стильно.
- [ ] **Neubrutalism (Необрутализм):** Дерзкий стиль. Жесткие черные рамки, жирные тени без размытия, контрастные "кричащие" цвета.
- [ ] **Clean & Airy (Воздушный минимализм):** Много белого пространства, тонкие серые линии, огромная красивая типографика.
- [ ] **Neumorphism (Неоморфизм):** Мягкий объем. Кнопки и панели словно "выдавлены" из самого фона (эффект пластика).
- [ ] **Cyberpunk / Hi-Tech:** Неоновые цвета, эффекты глитча, терминальные шрифты, технологичная сетка.
- [ ] **Retro / Y2K:** Намеренно винтажный стиль (Windows 95, пиксельные шрифты, ностальгические цвета).
- [ ] **Claymorphism (Глиняный 3D):** Воздушные, пухлые 3D-формы, пастельные тона, двойные тени (очень дружелюбный стиль).

## 2. "Изюминки" и Эффекты (Выберите 2-3 варианта)
- [ ] **Mesh Gradients (Жидкие градиенты):** На фоне плавно переливаются красивые, размытые цветовые пятна.
- [ ] **Magnetic Buttons:** Кнопки "примагничиваются" и тянутся за курсором мыши.
- [ ] **Micro-interactions:** Детальные анимации (иконка подпрыгивает, кнопка пульсирует).
- [ ] **Text Reveal:** Главные заголовки выезжают по буквам (эффект "маски" или печатной машинки).
- [ ] **Custom Cursor (Кастомный курсор):** Вместо обычной стрелочки мыши — красивая точка, кружок с инверсией цвета или шлейф.
- [ ] **Text Marquee (Бегущая строка):** Бесконечно плывущая лента огромного текста на фоне или на границах секций.
- [ ] **3D Tilt (Наклон карточек):** При наведении мыши карточки товара красиво наклоняются в 3D-пространстве (эффект параллакса курсора).

## 3. Скролл-Эффекты (Scroll Experiences)
*Это сделает сайт похожим на премиальные проекты с Awwwards или сайты Apple.*
- [ ] **Scroll Reveal:** Элементы плавно выплывают из невидимости по мере скролла вниз.
- [ ] **Parallax (Параллакс):** Фон или некоторые картинки двигаются медленнее текста (эффект 3D-глубины).
- [ ] **Sticky Sections (Залипающие секции):** При скролле заголовок "прилипает" к экрану, а контент едет мимо.
- [ ] **Horizontal Scroll (Горизонтальный скролл):** Крутите колесико вниз, а секция (галерея) едет вбок.
- [ ] **Scroll Snapping (Магнитный скролл):** Сайт "примагничивается" строго к экранам (как лента TikTok).
- [ ] **Scrubbable Animation (Анимация по скроллу):** Элемент (например, шестеренки инвертора) вращается ровно с той скоростью, с которой вы крутите колесико (Apple-style).
